# DecodeLabs AI Internship Projects

This repository contains the implementation of four Artificial Intelligence projects completed during the **DecodeLabs Industrial Internship Program – Batch 2026**.

## Projects Overview

### 1. Rule-Based AI Chatbot
- Implements deterministic, keyword-based response generation.
- Uses string sanitization with `.lower().strip()` for consistent input processing.
- Includes fallback responses for unrecognized user queries.

### 2. Data Classification Using K-Nearest Neighbors (KNN)
- Implements a supervised machine learning classification pipeline using the Iris dataset.
- Uses `StandardScaler` for feature normalization.
- Evaluates model performance using Scikit-learn evaluation metrics.

### 3. AI Recommendation Engine
- Implements content-based filtering to generate personalized recommendations.
- Uses TF-IDF Vectorization to convert text into numerical representations.
- Applies Cosine Similarity to identify and rank the most relevant items.

### 4. Machine Perception – Object Detection
- Implements an object detection pipeline using OpenCV's Deep Neural Network (DNN) module.
- Uses the pre-trained MobileNet-SSD model for object detection.
- Applies an 80% confidence threshold to filter detection results.

## Technologies Used

- Python
- Scikit-learn
- OpenCV
- NumPy
- TF-IDF Vectorization
- Machine Learning
- Computer Vision

## Repository Purpose

This repository demonstrates practical implementations of rule-based AI, supervised machine learning, recommendation systems, and computer vision as part of the DecodeLabs Industrial Internship Program.
